# Agent Review — Karbon Optimization

## Verdict

Karbon is a stretch role, but it is worth applying if the form allows explanation. It is highly aligned with the target career lane: Implementation Specialist, Client Onboarding, Product Support, and Customer Success.

## Listing signals to match

Karbon wants someone who can:

- Own customer implementation journeys.
- Manage project plans, milestones, deliverables, and risks.
- Lead kickoff, configuration, and training sessions.
- Communicate with firm administrators and key users.
- Support workflow setup and day-to-day usage.
- Coach customers through change management.
- Support data integrity using Excel and other tools.
- Collaborate with Sales, Customer Success, Product, and Support.
- Use AI in daily implementation work for planning, communication, and process improvement.

## Main risk

The posting asks for 2–4+ years of B2B SaaS implementations and end-to-end technical implementation experience. Chien should not claim that directly.

## Best positioning

Use this honest line:

> I have not held a formal B2B SaaS Implementation Specialist title. I do bring years of customer-facing ownership, training/documentation proof, milestone-style follow-through, AI-assisted workflow habits, and intentional focus on onboarding and implementation as my next role.

## Resume direction

Use `resume.md` as the current strongest draft.

Emphasize:

- customer-facing ownership
- onboarding and implementation support
- milestone tracking
- training and walkthroughs
- workflow documentation
- spreadsheets and data accuracy
- AI-assisted documentation
- change-management mindset
- remote readiness

Avoid:

- claiming accounting domain experience
- claiming Karbon platform experience
- claiming formal B2B SaaS implementation years
- claiming data migration ownership beyond practice or support-style familiarity

## Proof artifact

Use `proof-artifact.md` as a small supplemental artifact if the application allows links or if outreach needs a credibility boost.

It should be described as an illustrative preparation artifact, not prior employment.

## Cover letter direction

The cover letter should be direct about the gap but confident about the transfer:

- This is a stretch.
- This is the target lane.
- Chien brings customer ownership, documentation, technical learning, AI workflows, and implementation-style thinking.
- Karbon's AI-powered practice management platform is a strong match for his direction.

## Application decision

Proceed unless the form has a hard gate requiring formal B2B SaaS implementation experience with no explanation.
